# Producto: Commander rápido y social

## Principios de UX

- La mesa de cuatro es el diseño de referencia: tres oponentes visibles, mano propia amplia, pila persistente y texto legible.
- El pase automático está activo por defecto sólo cuando el motor no encuentra acciones legales visibles. El usuario puede apagarlo para bluff/counters.
- Un toque largo en móvil o clic secundario en desktop fija un **stop point** para una fase/paso y asiento; al llegar, el motor pide prioridad aunque el auto-pass esté activo.
- Al entrar a una sala pública de cuatro, los asientos se aleatorizan por defecto. La sala puede desactivarlo para grupos coordinados.
- Las recompensas son medallas originales del producto; no reutilizar iconos, arte ni marcas de Wizards.

## Alcance por versiones

| Versión | Resultado |
| --- | --- |
| Alpha cerrada | Commander 4 jugadores, salas privadas, motor para cartas seleccionadas y logs reproducibles. |
| Beta | matchmaking público 2–8, perfiles, lista de deseadas, torneos y reconexión. |
| Lanzamiento | Android, navegador y desktop; observadores, moderación, analítica y expansión progresiva de reglas/cartas. |

"Todas las cartas" significa dos cosas distintas: **catálogo** completo y **reglas ejecutables** completas. El catálogo puede llegar primero mediante datos de cartas; la ejecución se publica por cobertura mecánica verificable, nunca fingiendo que una carta es jugable si aún no lo es.
