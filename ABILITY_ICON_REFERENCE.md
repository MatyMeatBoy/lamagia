# Iconos de habilidades

Referencia visual: [MagicArena Wiki — Ability Icon](https://magicarena.fandom.com/wiki/Category:Ability_Icon).

## Uso permitido en el proyecto

La página sirve para estudiar jerarquía, agrupación y utilidad de iconos en una
mesa digital. No se descargan ni redistribuyen iconos de MTG Arena/Wizards.
`apps/client/src/abilities.ts` contiene SVG originales de ProsshTCG, con ayuda
de reglas y una nota explícita de qué aplica realmente el motor.

## Regla de UX

Un icono debe indicar una habilidad reconocida, su disponibilidad actual y abrir
la explicación correspondiente. Nunca debe convertir una habilidad no
implementada en una promesa visual de que funciona.
