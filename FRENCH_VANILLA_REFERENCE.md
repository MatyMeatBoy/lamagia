# French-Vanilla como referencia de CR

[Repositorio](https://github.com/didymusbenson/French-Vanilla): aplicación
Flutter para navegar y buscar la Comprehensive Rules.

## Funciones útiles para nuestro trabajo

- Navegación por secciones y subreglas.
- Búsqueda full-text de reglas y glosario.
- Enlace y resaltado de subreglas concretas.
- Datos locales JSON derivados del Markdown de CR.
- Tests y scripts de actualización/parsing.

## Aplicación a ProsshTCG

French-Vanilla es especialmente útil como modelo de herramienta offline y para
encontrar rápidamente reglas relacionadas antes de diseñar un `SpellEffect`,
`GameEvent` o una elección. No se integra como dependencia de runtime. Su
licencia GPLv3 exige mantener cualquier componente derivado separado y revisar
licencias antes de reutilizar código o datos.
